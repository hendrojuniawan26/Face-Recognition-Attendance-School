Panduan Pengaturan Supabase (4 Langkah)

Ikuti urutan berikut untuk menghubungkan database absensi wajah Siswa & Guru secara realtime.

Buka Supabase Dashboard
1

Buat Proyek Baru

Masuk ke supabase.com, klik New project, beri nama proyek sekolah, pilih region terdekat (mis. Singapore), lalu tunggu proyek aktif.

2

Jalankan Skrip SQL

Buka menu SQL Editor → New query di Supabase, buka kunci skrip SQL dengan token akses, klik Salin SQL, tempel lalu klik Run hingga muncul Success.

3

Salin URL & Anon Key

Buka Project Settings → API (atau Data API). Salin Project URL dan kunci publik anon / publishable key (jangan pakai service_role).

4

Simpan & Uji Koneksi

Tempel kredensial pada form di bawah, lalu klik Simpan & Hubungkan. Pastikan status berubah menjadi Terhubung (Realtime Aktif).

Konfigurasi Koneksi Supabase

Kredensial disimpan secara lokal di browser ini (localStorage).

0.48

Nilai lebih kecil lebih ketat (mengurangi salah kenali), nilai default ideal: 0.48.

Skrip SQL Migrasi Supabase

Salin dan jalankan di menu SQL Editor pada proyek Supabase sekolah Anda.

Skrip SQL Disembunyikan

Skrip SQL migrasi database dilindungi. Masukkan token akses admin untuk melihat dan menyalin skrip.
